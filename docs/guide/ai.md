# AI 辅助写作

> 状态：规划中（P0 / P1）

Papex Writer 将 AI 嵌入写作全流程，且**每一步可单独关闭**。

## 能力矩阵

| 阶段 | 能力 | 默认 |
|------|------|------|
| 灵感 | 研究问题生成、贡献点提炼 | 开 |
| 大纲 | 章节结构建议 | 开 |
| 转写 | Markdown → 学术论文片段增强 | 开 |
| 写作 | 润色 / 扩写 / 缩写 / 学术化 / 翻译 | 润色开，续写关 |
| LaTeX | 表 / 公式生成、错误解释 | 开 |
| 引用 | 推荐引用位置 | 关 |
| 摘要 | 摘要 / 标题 / 关键词生成 | 开 |
| 审阅 | 一致性、缺图缺引、术语统一 | 开 |
| 导出 | 合规预检 | 开 |

## 端点

- OpenAI 兼容 API
- Anthropic 兼容 API
- 本地 Ollama
- 自定义 `baseURL`

无端点时 AI 功能显式禁用，编辑/编译/导出完全可用。

## 使用方式

- `Ctrl/Cmd + Shift + A` 打开 AI 浮动菜单
- 选中文字 → 润色 / 扩写 / 缩写 / 学术化
- 编译失败 →「AI 解释」
- 大纲面板 →「AI 建议结构」

## 原则

1. **不直接覆盖原文**（修订模式除外）
2. 生成结果可采纳 / 复制 / 插入 / 丢弃
3. 不用用户数据训练
4. 外发前告知上下文范围（可选「仅发送选区」）
5. 详见 [AI 端点与隐私](../reference/ai-privacy)
