# 创意工作流

> 状态：规划中（P0）

创意库帮助你在正式成文前捕获研究想法。

## 概念

- **灵感（Idea）**：一条可带标签的短文本卡片
- **收件箱（Inbox）**：尚未绑定章节的灵感
- **升格（Promote）**：把灵感插入为指定章节的草稿段落

## 推荐流程

1. 随时用 `Ctrl/Cmd + Shift + I` 快速记一条灵感
2. 给灵感打标签（`method`、`todo`、`related`…）
3. 写作某章节时，在创意库筛选标签，点「插入到章节」
4. 处理完的灵感标记为「已归档」

## 数据位置

灵感保存在项目目录 `.papex-writer/project.json`，**不会**进入导出的投稿包。
