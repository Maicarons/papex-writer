# 命令行

开发脚本见 `package.json`：

| 命令 | 说明 |
|------|------|
| `npm run dev` | 启动 Electron 开发模式 |
| `npm run build` | 类型检查并构建 |
| `npm run dist` | 生成安装包 |
| `npm run test` | 单元测试 |
| `npm run e2e` | 端到端测试 |
| `npm run lint` / `typecheck` | 静态检查 |
| `npm run docs:dev` | 文档站开发预览 |
| `npm run sync:latex` | 同步 papex-latex 资源 |
| `npm run verify:example` | 校验与上游 example 一致 |
