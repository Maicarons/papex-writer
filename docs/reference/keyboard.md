# 快捷键

| 快捷键 | 动作 |
|--------|------|
| `Ctrl/Cmd + S` | 保存项目 |
| `Ctrl/Cmd + N` | 新建章节 |
| `Ctrl/Cmd + Shift + P` | 命令面板 |
| `Ctrl/Cmd + Shift + V` | 源码 / 所见即所得切换 |
| `Ctrl/Cmd + Shift + M` | 选区 Markdown 转论文片段 |
| `Ctrl/Cmd + Shift + A` | AI 浮动菜单 |
| `Ctrl/Cmd + B` | 编译当前项目 |
| `Ctrl/Cmd + E` | 导出投稿包 |
| `Ctrl/Cmd + K` | 引用 / 命令快速插入 |
| `Ctrl/Cmd + Shift + I` | 快速记灵感 |
| `Ctrl/Cmd + F` / `H` | 查找 / 替换 |
| `Ctrl/Cmd + /` | 切换注释 |

> 草案，实现阶段可能微调；以应用内命令面板为准。
