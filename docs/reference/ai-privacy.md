# AI 端点与隐私

## 数据流

```text
编辑器上下文（选区/章节/日志）
        │
        ▼
  AI Orchestrator（本地）
  · 展示将发送的范围
  · 审计日志
        │
        ▼
  你配置的端点
  （Ollama 本地 / OpenAI 兼容 / Anthropic / 自定义）
```

## 隐私承诺

| 项 | 说明 |
|----|------|
| 训练 | 不使用你的项目数据训练任何模型 |
| 最小化 | 默认可只发送选区；全文发送前确认 |
| 本地优先 | 推荐 Ollama 等本地端点 |
| 可关闭 | 全局开关 + 每类能力独立开关 |
| 透明 | 使用第三方端点时在设置中明确列出 |

## 学术诚信

- 机构/期刊对 AI 使用有不同规定，请自行遵守
- 可启用「AI 仅辅助结构」模式（禁用改写类能力）
- AI 不会为你编造参考文献；引用 key 必须来自文献库

## 配置路径

`设置 → AI → Provider`：填写 `baseURL`、模型名、API Key（存系统钥匙串）。
